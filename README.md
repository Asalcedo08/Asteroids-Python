# Asteroids-Python
Game created to learn OOP fundamentals in python started from boot.dev

# Features

UI Bar:
- Shows number of lives player has and can have
- Shows bombs player currently has and can have
- Shows current score, 1 asteroid = 1 point

Asteroids:
- Fly around the screen
- Collision with bomb destroys fully
- Collision with bullet or bomb explosion causes split
- Game over on player collision
- Wrap around the screen if passing the edges

Player:
- Shoots asteroids using bombs and bullets
- Wraps around the screen if it goes ove the edge

Keybinds: 
- W: Move forward
- S: Move backward
- A: Rotate left
- D: Rotate right
- Space: Shoot bullet (0.3 second cooldown)
- L-Shift: Shoot bomb (3 second cooldown)
